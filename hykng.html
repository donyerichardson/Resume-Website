Hykng

This project, created by Donye Richardson, showcases a hiking-focused website accessible by clicking the photo. It includes a Home Page with an overview, an About Me/Contact Me Page sharing personal hiking experiences, a Trail Guide highlighting favorite Georgia trails and tips, and a Hiking Gear Page summarizing essential gear for successful hikes. The Hiking Map Page is an interactive feature showcasing different hiking points in the metro Atlanta area. By clicking on pins, users can access detailed descriptions of various trails, making it a practical tool for planning outdoor adventures. This project reflects a passion for hiking and inspires others to explore nature.

by Donye Richardson
