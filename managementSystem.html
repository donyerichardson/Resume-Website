Project Management System

A web-based tool designed to simplify project tracking and management. Built using HTML, CSS, and JavaScript, it allows users to enter high-level project descriptions, define functional and non-functional requirements, log efforts across various tasks, and view detailed summaries. With interactive navigation and real-time feedback, the system provides a seamless user experience for managing project details efficiently. Developed by Donye Richardson, Ali Ali, and Zarin Tanisa, it offers a clean and intuitive interface for team collaboration. Click the photo to interact with it
